## Problems found (fix after the wave)

1. **The cloud's first saves all land on one creature** (rows 4, 18). When the cloud appears, Midi runs "Breathe the cloud" once per creature inside, all at the same moment; each run is handed the right creature, but the runs trip over each other and all three save cards target the same creature. Walk-ins and turn starts (one at a time) target correctly. Midi-QoL 14.0.12 behavior with simultaneous region triggers.
2. **This world's calendar ends long effects early** (row 21). Not the module's bug, but it ends addictions: a withdrawal whose end falls past the coming year boundary reads 0 or a few days remaining, so House Automation deletes it at the next turn change or time update and the module ends the addiction. Raw seconds are right; Foundry's calendar difference across the leap year is wrong. Worth checking the Tatharian Calendar's leap-year setup (364 days vs 360). The module could also guard: end the addiction only when the withdrawal's recorded end has passed.
3. **A restocked single-use pack stays empty** (row 22): dropping a new Rolling Papers pack onto a used-up one stacks the quantity but keeps the used count, so the gear check still sees it as empty. dnd5e itself rolls over to the next pack when it consumes uses; the module's spend and readiness don't.
4. **Each drug's own action shows as "Midi Use"** on the sheet (row 6): the self-use activity has an empty name, so Midi's default label shows. Name it "Use" (spec mockup 1).
