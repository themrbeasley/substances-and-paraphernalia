# v0.9.2 leftovers: plan and tracker

**Spec:** `docs/superpowers/specs/2026-09-30-v0.9.2-leftovers-design.md` (approved 2026-09-30). Decision ids (D1 to D13) below point there.

**Execution:** native, one commit per task, on branch `claude/superpowers-module-dev-ca64bd` (worktree). Small changes are checked directly; one whole-branch review at the end. Each task runs `npm run lint`, `npm run validate` and `npm run test:unit` before its commit. New test files go into the `test:unit` list in `package.json`.

**Global constraints:**
- Foundry V14 / dnd5e 5.3.x only.
- No em or en dashes anywhere.
- Pure helpers in `scripts/data/` (no Foundry globals) with tests; Foundry wrappers in `scripts/hooks/`.
- AE data shape only through `effect-data.js`.
- Flags only through `flag-schema.js`.
- User-facing text through `lang/en.json`, with no dotted-prefix collisions.

## Tasks

1. **Roll windows.**
   - `roll-config.js`: add `rollWithoutSkipping(roll, config)`. It calls `roll(config)`; if the result is an empty array, null or undefined, it calls `roll(config, { configure: false })`, then unwraps an array to its first roll.
   - Tests: a first call returns `[]`, then the second call gets `{ configure: false }`; a roll on the first try is returned and roll is called once.
   - `addiction.js` `rollSave`, and `long-rest-abstain.js` `rollAbstainCheck` / `rollWithdrawalSave`: use it. Drop `rollAbilitySave` and the "window closed" returns; keep a guard for a missing roll function.
2. **Blank DCs.** In `flag-schema.js`:
   - `getAbstain` returns null unless `abstain.dc` is a finite number and not null or "".
   - `getWithdrawalDc` returns null for null and "".
   - `getToleranceDecay` uses the default for null, "" and missing.

   In `long-rest-abstain.js`: when the Withdrawal DC is null, skip the save and apply withdrawal, with a chat line. Validator: shipped content errors on a null or "" Abstain DC and Withdrawal DC. Tests for each getter and the validator.
3. **Dose steps.**
   - `addiction.js`: a `step(label, fn)` helper catches and logs each of the five pipeline steps; `onPostUseActivity` keeps its outer catch.
   - `long-rest-abstain.js`: try/catch per drug around the fade loop.
4. **Highs.**
   - `prior-high.js` `isPriorHigh`: accept no role plus a name matching /altered/i.
   - Tests: name fallback, plus `isStrayHigh` with no origin and with no items.
   - `module.mjs`: add `onPreCreateActiveEffect` to `api.addiction`.
5. **Addicted and recovery.**

   - `withdrawal-cleanup.js`: use the predicate, key `inFlight` on `actor.uuid`, and move the decision into a pure `scripts/data/recovery.js` `recoveryAction({ relapse, withdrawalsLeft, addictionIds })` with a test.

6. **Withdrawal paths.**
