# v0.9.0 Foundry V14 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Substances and Paraphernalia run correctly on Foundry V14 build 368 with dnd5e 5.3.3, with no deprecated calls from our code and guards that keep them out.

## Global Constraints

- Foundry core: `compatibility: { minimum: "14", verified: "14.368" }`, no `maximum`. V13 is dropped.
- dnd5e: `{ minimum: "5.3.0", verified: "5.3.3" }`.
- Module version: `0.9.0`.
- `relationships.requires` stays `dae`, `midi-qol`, `tokenmagic`. `times-up` is removed from `recommends`.
- Anything under `test/unit/` imports must load in plain Node: no `game`, `Hooks`, `ui`, `CONFIG` or `CONST` at import time.
- New `test/unit/*.test.mjs` files must be added to the explicit list in `package.json` `test:unit`.
- Change values are *written* as strings. Readers must accept strings, numbers, booleans and arrays.
- Effect durations we set are always `units: "seconds"`. Months are 30 days (`durationToSeconds`).
- Expired-effect deletion is **not** this module's job (House Automation switch, spec A4). Don't add an expiry handler.
- `lang/en.json`: no key may be a strict dotted prefix of another key (existing guard test).
- Commits go on branch `claude/foundryvtt-plugin-v14-905176` only. Nothing is pushed before Task 9's user gate.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs the spec implies but no happy-path test exercises, most likely to bite first. Each has a test in the owning task:

1. **A substance with no authored withdrawal duration.** The builders compute 0 seconds. V14 treats `value: 0` as already expired (V13 treated 0 as no duration). Expected: the effect is permanent, as on V13. Test in Task 1.
2. **World effects that V14 core migrated.** V14's converter `JSON.parse`s legacy string values, so bypass and tolerance rows hold real arrays, booleans and numbers. Expected: they decode to the same modifier block as the string form. Test in Task 3.
3. **A template carrying a stale `start`** (an item effect copied from an actor, or authored mid-combat). Expected: V14 stamps a fresh start and the effect doesn't expire on arrival. Test in Task 1.
4. **A template with an `expiry` event, made permanent** (addiction, drag-to-inventory benefit). Expected: it doesn't expire at the next turn start. Test in Task 1.
5. **Altered templates whose values are native numbers or non-numeric strings** (a V14-migrated world item; a `macro.tokenMagic` preset name). Expected: numbers scale with tolerance and preset names pass through untouched. Test in Task 1.

- [ ] **Step 5: Implement `scripts/data/effect-data.js`**

```js
/**
 * Foundry V14 Active Effect data helpers.
 *
 * V14 moved change rows to `system.changes` (string `type` instead of numeric
 * `mode`), stores duration as `value` + `units`, treats `value: 0` as already
 * expired, and keeps any `start` already present on data passed to create.
 * Every effect this module creates goes through `prepareEffectPayload`, so
 * those rules live here and nowhere else.
 *
 * Pure: operates on plain data (e.g. `template.toObject()`), so it runs under
 * `node --test` without Foundry globals.
 */

import { MODULE_ID, FLAGS } from "../config.js";

/**
 * Change rows of an effect document or plain effect data.
 * @param {object|null|undefined} effect
 * @returns {Array<{key:string, type:string, value:any, priority?:number}>}
 */
export const effectChanges = (effect) => effect?.system?.changes ?? [];

/**
 * Turn template data into a create payload for an actor-owned effect.
 * Mutates and returns `data`.
 *
 * @param {object} data  Plain effect data (e.g. `template.toObject()`).
 * @param {object} opts
 * @param {string} opts.sourceSubstanceId  Substance item id, stamped into our flags.
 * @param {string} opts.origin             Substance item UUID.
 * @param {string} [opts.role]             `aeRole` flag value; left alone when omitted.
 * @param {number|null} [opts.duration]    `undefined` keeps the template's duration;
 *   `null` or a non-positive number makes the effect permanent; a positive
 *   number sets that many seconds.
 * @returns {object}
 */
export function prepareEffectPayload(data, { sourceSubstanceId, origin, role, duration } = {}) {
  delete data._id;
  delete data.start; // V14 keeps an incoming start; a stale one can expire the effect on arrival.
  data.flags = data.flags ?? {};
  data.flags[MODULE_ID] = {
    ...(data.flags[MODULE_ID] ?? {}),
    [FLAGS.sourceSubstanceId]: sourceSubstanceId,
    ...(role ? { [FLAGS.aeRole]: role } : {}),
  };
  data.origin = origin;
  data.disabled = false;

  if (duration === undefined) return data;
  if (typeof duration === "number" && duration > 0) {
    data.duration = { ...(data.duration ?? {}), value: duration, units: "seconds", expired: false };
  } else {
    // Permanent. Clearing `expiry` matters: V14 counts an effect with an expiry
    // event as temporary even without a value, and would expire it at that event.
    data.duration = { ...(data.duration ?? {}), value: null, expiry: null, expired: false };
  }
  return data;
}
```

- [ ] **Step 6: Implement `attenuateChangeRows` in `scripts/data/tolerance.js`**

Add below `applyAttenuation`:

```js
/**
 * Scale every numeric change-row value by the attenuation curve at `count`.
 * Values are parsed from strings or taken as numbers (V14-migrated data holds
 * real numbers), and written back as strings. Non-numeric values such as
 * `macro.tokenMagic` preset names pass through unchanged.
 *
 * @param {Array<{value:any}>|null|undefined} rows
 * @param {number} count
 * @param {number[]} curve
 * @returns {Array<object>} new rows; the input is not mutated
 */
export function attenuateChangeRows(rows, count, curve) {
  return (rows ?? []).map((row) => {
    const n = Number(row.value);
    const scaled = applyAttenuation(Number.isFinite(n) ? n : row.value, count, curve);
    return { ...row, value: typeof scaled === "number" ? String(scaled) : scaled };
  });
}
```

Note: this is exactly the inline code it replaces in Task 2 (`parseScalar` → `applyAttenuation` → `stringifyScalar`), moved somewhere testable. That includes its quirks: `Number("")` and `Number(true)` are finite, so an empty-string value comes out as `"0"`, the same as before. Don't change those here.

// Throwaway: convert _source Active Effects to the Foundry V14 shape.
// Run from the repo root: node "$SCRATCH/convert-ae-v14.mjs"
import fs from "node:fs";
import path from "node:path";

const MODE_TO_TYPE = { 0: "custom", 1: "multiply", 2: "add", 3: "downgrade", 4: "upgrade", 5: "override" };
const LEGACY_DURATION = ["seconds", "rounds", "turns", "startTime", "startRound", "startTurn", "combat"];

const convertRows = (rows) =>
  rows.map(({ mode, ...row }) => ({ ...row, type: MODE_TO_TYPE[mode] ?? `custom.${mode}` }));

// Rebuild the effect with `system` in the slot `changes` occupied, so key order
// (and the trailing `_key` the fvtt CLI writes) stays put and the diff stays small.
function convertEffect(e) {
  const out = {};
  for (const [k, v] of Object.entries(e)) {
    if (k === "changes") out.system = { ...(e.system ?? {}), changes: convertRows(v) };
    else if (k !== "system" || !Array.isArray(e.changes)) out[k] = v;
  }
  if (out.duration && typeof out.duration === "object") {
    const d = { ...out.duration };
    for (const unit of ["seconds", "rounds", "turns"]) {
      if (typeof d[unit] === "number" && d.value === undefined) {
        d.value = d[unit];
        d.units = unit;
      }
    }
    for (const key of LEGACY_DURATION) delete d[key];
    out.duration = d;
  }
  return out;
}

let effects = 0;
for (const pack of fs.readdirSync("_source")) {
  for (const file of fs.readdirSync(path.join("_source", pack))) {
    if (!file.endsWith(".json")) continue;
    const p = path.join("_source", pack, file);
    const doc = JSON.parse(fs.readFileSync(p, "utf8"));
    if (!Array.isArray(doc.effects) || doc.effects.length === 0) continue;
    doc.effects = doc.effects.map(convertEffect);
    effects += doc.effects.length;
    fs.writeFileSync(p, JSON.stringify(doc, null, 2) + "\n");
  }
}
console.log(`converted ${effects} effects`);
